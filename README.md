# 数据透视经理 - 企业数据分析 SaaS
**项目描述**：一个为求职者和投资者提供快速、深度企业数据分析的SaaS服务。我们通过解析公开数据，帮助用户一键生成易懂的企业洞察报告。
---
## 🎯 项目愿景
让每个人在 **5分钟** 内，都能像专业分析师一样看透任何一家公司的**基本面、风险和潜力**。
## ✨ 核心价值
- **对于求职者**：面试前快速评估目标公司的稳定性、技术实力和发展前景，避免入坑。
- **对于投资者/分析师**：快速完成公司初筛，定位关键风险点（如法律诉讼、股权质押），提升尽调效率。
## 🚀 当前进展
- ✅ **商业模型验证**：已完成市场分析与产品定位
- ✅ **数据源打通**：已完成天眼查等平台的核心数据爬虫原型
- ✅ **产品原型设计**：已规划最小可行产品功能清单
- 🚧 **技术开发**：正在搭建 Django 后端 Web 服务
- 🔜 **下一步**：实现用户前端界面与支付闭环
## 🛠 技术栈
| 领域 | 技术选型 |
| :--- | :--- |
| **后端** | Python, Django, Django REST Framework |
| **数据获取** | Requests, BeautifulSoup, 反爬虫策略 |
| **前端** | Vue.js, Element Plus, Bootstrap |
| **数据存储** | PostgreSQL, Redis (缓存) |
| **部署** | Docker, Nginx, 云服务器 |
